接口不通时：粘贴 JSON 继续用

浏览器的跨域策略加上 Bangumi 接口本身的限制，直接在网页里调用有可能失败 （本工具的实测结论与原因见 README）。这时可以用下面这条不用跨域的路子： 在浏览器新标签里打开接口地址，把返回的 JSON 整段复制过来粘贴即可。
怎么拿到这段 JSON？（点开看步骤）
要作品列表：新标签打开
https://api.bgm.tv/search/subject/关键词?type=2&responseGroup=small
把地址里的「关键词」换成你要搜的作品名（中文也行），回车后页面上会显示一段 JSON，全选复制。

要某部作品的角色：先在 Bangumi 网页找到作品，记下地址里的数字 ID（形如 bgm.tv/subject/38040 里的 38040）， 然后新标签打开
https://api.bgm.tv/v0/subjects/作品ID/characters
同样会直接显示一段 JSON，全选复制。

小贴士：直接在地址栏打开是不带 Origin 头的普通导航请求，所以能正常返回； 而在网页里用 fetch 会被浏览器加上 Origin 头，这正是接口会失败的原因之一。 粘贴的 JSON 支持这几种形状：作品的 {"data":[...]} / {"list":[...]} / [...]， 角色的 [{name,images,relation}] / {"crt":[...]}。
